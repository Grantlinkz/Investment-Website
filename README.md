# Investment Website

A Simple Website For Trading And Investment.

Overview
- A simple trading and investment demo site with portfolio and simulated trading actions.
- Primary languages: CSS, JavaScript, PHP, SCSS, Hack, HTML, Sass.

Key Features
- Portfolio overview and simulated buy/sell flows
- Price/asset listings and transaction logs
- Responsive UI and demo pages

Tech Stack
- Frontend: HTML, JavaScript, CSS, SCSS
- Backend: PHP, Hack
- Database: MySQL

Getting Started
1. Clone:
   git clone https://github.com/Grantlinkz/Investment-Website.git
2. Configure a PHP environment and database.
3. Update config/database files with credentials and any required API keys.
4. Start your server and open the site.

Usage
- Use the dashboard to simulate trades, view the portfolio, and inspect transaction history.
